タックスピアのランプをブランド正本の千歳緑 `#316745` へ再アンカーした。

正本は Polastack_GTM `brand-assets/`（manifest v1.2.0・CEO 裁定 2026-08-19）。
ロゴ資産 `taxpeer/logo-*.svg` が持つ hex と操作段を一致させる。

色相を 156.0° → 154.2°（正本 500 の実測 H）へ寄せ、500 段を正本値に固定した。
L と C は据え置き（契約 L に載っており、500 の既存逸脱もそのまま）。

| 段 | 旧 | 新 |
| --- | --- | --- |
| 50 | `#eaf3ec` | `#eaf3ec` |
| 100 | `#c3e0cc` | `#c3e0cb` |
| 200 | `#9dcfaf` | `#9fcfad` |
| 300 | `#6abc8b` | `#6dbc88` |
| 400 | `#5aa176` | `#5ca174` |
| 500 | `#2f6847` | `#316745` |
| 600 | `#3e7152` | `#407151` |
| 700 | `#325d43` | `#335d42` |
| 800 | `#1d4630` | `#20462e` |
| 900 | `#1b3626` | `#1c3625` |
| 950 | `#0f2216` | `#0f2216` |

旧 500 との差は ΔL 0.002 / ΔC 0.0008 / ΔH 1.8° で視覚的には同一。
`[data-brand="peerdesk-taxpeer"]` を使っていないサイトへの影響はない。

正本の「ライト `#A3B5AA`」はランプに入れていない。あれはロゴ意匠の第 2 色
（ふくろうのヘッドセット・C 0.025）で、装飾段 300（C 0.108）とは役割が違う。
ピアデスクで「ライト = 300 段」が一致するのは親が無彩ブランドだからで、
彩度のあるタックスピアに同じ写像をすると装飾段が鈍る。
